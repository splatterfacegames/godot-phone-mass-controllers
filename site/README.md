# site/

The project website for godot-phone-mass-controllers — a static, dependency-free explainer
(no build step, no framework). Everything is hand-written HTML/CSS/vanilla JS and works over
`file://` as well as https.

Deployed automatically by [.github/workflows/pages.yml](../.github/workflows/pages.yml) to
GitHub Pages on every push to `main` that touches `site/`. Served at the custom domain
**pmc.jethachan.net** (see `CNAME`; DNS via Cloudflare → GitHub Pages).

- `index.html` — the page
- `style.css` — the only stylesheet
- `app.js` — the simulated lobby widget in the hero area
- `assets/` — demo screenshots (copied from `docs/`) plus `repo-qr.png`, a QR of the repo URL
  generated by the addon's own `PMCQr` encoder
